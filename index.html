Reality check. Puzzle #72 has a 2⁷¹ keyspace (≈2.36×10²¹ keys). Even a top-end GPU at billions of keys/s would need thousands of years to exhaust it; this browser engine is far slower. Treat this as a research/educational tool and a lottery with astronomically low odds, not an income strategy. If a match is ever found it is shown only on this device and never transmitted.

About

LudKey Hunter standalone web engine. secp256k1 + SHA-256 + RIPEMD-160 implemented in pure JavaScript, verified in-browser against known test vectors at startup, and run in Web Workers (one disjoint sub-range each — no duplicated work). The same algorithms have a WebGPU/WGSL acceleration path and a native CUDA desktop agent in the full project source.
