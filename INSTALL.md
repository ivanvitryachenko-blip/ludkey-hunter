# LudKey Hunter — установка и запуск

Есть три способа пользоваться. Самый простой — первый, он не требует установки.

---

## Вариант 1. Веб-приложение (ничего не устанавливать)

Это один самодостаточный файл `apps/web-standalone/index.html`. Он работает
офлайн и на любом устройстве (Windows, Mac, Linux, iPhone, Android).

**Как открыть:**
- Просто откройте опубликованную ссылку приложения в браузере, **или**
- скачайте файл `index.html` и откройте его двойным кликом (он откроется в
  браузере по умолчанию), **или**
- положите его на любой статический хостинг и откройте по адресу.

**Как пользоваться:**
1. Вкладка **Search**.
2. **Mode** — выберите:
   - *Puzzle #71 — sequential* — последовательный перебор, возобновляется после
     перезагрузки;
   - *Puzzle #71 — random, no-repeat* — случайные сегменты без повторов,
     пройденные сохраняются;
   - *Demo* — спрячет известный ключ и реально его найдёт (проверка, что всё
     работает).
3. **Compute backend**:
   - *CPU* — работает везде;
   - *GPU (WebGPU)* — на видеокарте, где браузер поддерживает WebGPU
     (лучше всего Chrome/Edge на десктопе);
   - *Hybrid (CPU + GPU)* — CPU и GPU одновременно, скорости складываются;
   - *Auto* — GPU если проходит самотест, иначе CPU.
4. **Workers** — число потоков CPU (ставьте по числу ядер, напр. 8).
5. Нажмите **Start**.

Прогресс хранится в этом браузере. Бэкап/перенос — вкладка **Settings →
Backup & restore progress** (кнопки Copy backup / Download / Restore).

Важно: внутри браузера-песочницы (по ссылке) автоматическая рассылка
транзакции и запрос баланса недоступны — там показывается WIF для ручного
импорта. Полная автоматика (`--payout`) есть в версии ниже.

## Вариант 2. Запуск исходников локально (CPU-движок, сервер, автоклейм)

**Требуется:** Node.js версии 22 или новее — https://nodejs.org (возьмите LTS).
Проверка: `node --version` должно показать `v22.x` или выше.

```bash
# распаковать архив и зайти в папку
tar -xzf ludkey-hunter.tar.gz
cd ludkey-hunter

npm test            # прогнать все тесты (должно быть ALL SUITES PASSED)
npm run demo        # движок находит спрятанный ключ (доказательство)
npm run bench       # измерить реальную скорость на вашем CPU
```

Реальный поиск по участку диапазона #71 (Ctrl-C сохраняет прогресс, повторный
запуск продолжает с того же места):
```bash
npm run search -- --start 400000000000000000 --end 4000000000ffffffff
```

Автоматически собрать и подписать перевод на свой кошелёк при находке
(ключ не покидает машину; по умолчанию не рассылается — печатает подписанную
транзакцию; `--broadcast` включает публичную рассылку осознанно):
```bash
npm run search -- --start 4000... --end 4000... --payout bc1qВАШ_КОШЕЛЁК
```

## Вариант 3. ОДНА общая цель: телефон + все компьютеры вместе

Это главный сценарий: все ваши устройства ищут по одному диапазону #71,
каждому достаётся свой непересекающийся участок, а скорости складываются.
Нужен один «координатор» — сервер, который раздаёт участки и считает общий
прогресс. Он же отдаёт само веб-приложение, поэтому на всех устройствах
открывается ОДИН адрес.

### Шаг 1. Запустите координатор на одной всегда-включённой машине
```bash
npm run server
# по умолчанию порт 8071; сервер печатает адрес и что отдаёт приложение на /
```
Совет: для парка из телефонов задайте небольшой размер сегмента, чтобы даже
телефон успевал завершать участок (иначе сегмент по умолчанию огромный):
```bash
# Windows PowerShell:
$env:LUDKEY_CHUNK=16777216; npm run server      # сегмент 2^24 ≈ 16.7M ключей
# macOS/Linux:
LUDKEY_CHUNK=16777216 npm run server
```

### Шаг 2. Откройте один адрес на всех устройствах
- **Дома, в одной Wi-Fi сети (проще всего, без интернета):** узнайте
  локальный IP машины с сервером (Windows: `ipconfig` → IPv4, обычно
  `192.168.x.x`). На телефоне и других ПК в той же сети откройте в браузере
  `http://192.168.x.x:8071/`. Готово — приложение уже настроено на этот сервер.
- **Устройства в разных местах (через интернет):** нужен публичный HTTPS-адрес.
  Бесплатно и просто — туннель Cloudflare:
  ```bash
  # установите cloudflared, затем:
  cloudflared tunnel --url http://localhost:8071
  ```
  он выдаст адрес вида `https://что-то.trycloudflare.com` — открывайте его на
  всех устройствах. (Альтернативы: ngrok, или сервер на VPS с доменом и TLS.)

### Шаг 3. На каждом устройстве
В приложении: **Mode → «Connected — shared search across ALL your devices» →
Start**. Если вы открыли приложение по адресу координатора, поле URL можно
оставить пустым (он подставится сам). На дашборде вы увидите **общую скорость
всех устройств** и список устройств; сервер гарантирует, что никто не
дублирует чужой участок.

### Максимальная скорость на мощных ПК
Телефоны и ноутбуки удобно гонять прямо в браузере (Connected). На ПК с
видеокартой NVIDIA дополнительно запустите нативный агент против того же
сервера — он присоединится к той же общей цели:
```bash
npm run agent -- --server http://АЙПИ:8071 --name rig-rtx --payout bc1qВАШ_КОШЕЛЁК
# либо CUDA-агент (см. ниже) — он тоже берёт участки у того же сервера
```

### Безопасность
Домашнюю машину не выставляйте напрямую в интернет: в одной сети хватает
локального IP, а для удалённого доступа используйте туннель/обратный прокси с
TLS. Найденный ключ сервер хранит только у себя (в файле `data/FOUND_KEY.json`)
и никогда не отдаёт по сети.

## NVIDIA GPU — нативный CUDA-агент (максимальная скорость)

**Требуется:** видеокарта NVIDIA + CUDA Toolkit (`nvcc`).

```bash
cd packages/agent-cuda
make SM=75        # GTX 1650=75, RTX 3070=86, RTX 5070/5090=120 (нужен CUDA 12.8+)
make validate     # самотест GPU↔CPU — должно напечатать [validate] PASS
./ludkey_cuda --server http://АЙПИ:8071   # присоединиться к общему поиску
```
Если самотест не напечатал `PASS` — поиск не запустится (защита от неверных
результатов). Этот код не компилировался в среде разработки, самотест на вашей
карте — обязательная проверка.

## Что где лежит

```
apps/web-standalone/index.html   веб-приложение (один файл)
packages/core                    проверенная криптография
packages/engine                  CPU-движок, CLI, бенчмарк, агент
packages/server                  сервер-координатор
packages/claim                   WIF, подпись транзакции, автоклейм
packages/agent-cuda              CUDA-ядро для NVIDIA
packages/web-webgpu              WGSL-ядро + модель проверки
```

## Минимальные требования
- Веб-приложение: любой современный браузер. WebGPU — Chrome/Edge на десктопе.
- Исходники: Node.js ≥ 22.
- CUDA-агент: NVIDIA GPU + CUDA Toolkit.
